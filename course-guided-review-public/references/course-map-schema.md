# Course and Exam Map

Build a compact, source-traceable map before claiming that the review covers the course. Keep it proportional to the material and update it as new evidence arrives.

## Course profile

- Course name and term
- Exam date and time remaining
- Exam format, duration, points, and allowed materials
- Official scope and exclusions
- Language and notation conventions
- Learner's target and current confidence

## Source coverage

For each source or source group, record:

- role: lecture, tutorial, assignment, past exam, official solution, personal note, textbook;
- coverage state from `source-audit.md`;
- topics and question types;
- source/page references;
- unresolved quality or completeness issues.

## Topic map

For each examinable topic, record:

| Topic | Required concepts | Standard method pipeline | Typical command words | Evidence | Mastery | Next action |
|---|---|---|---|---|---|---|

Use mastery labels that describe observable performance:

- **Unseen:** not yet introduced.
- **Recognizes:** understands a worked solution but cannot select the method alone.
- **Guided:** can proceed with prompts.
- **Independent:** can complete a representative question unaided.
- **Exam-ready:** can identify, solve, justify, and check under time pressure.

## Question-type map

For each recurring type, record:

- what the prompt is asking for;
- recognition signals;
- first line to write or first action to take;
- full course-approved pipeline;
- common branches or special cases;
- frequent errors;
- representative source questions;
- expected justification or theorem language.

## Instructor/course conventions

Record only evidence-backed conventions:

- preferred notation and variable order;
- approved solution methods;
- expected level of derivation and justification;
- recurring theorem statements or command-word interpretations;
- grading cues found in rubrics or official solutions.

Do not model personality, humor, or speculative preferences.

## Evidence labels

Attach one or more labels to claims:

- **Confirmed scope:** explicitly included by an official source.
- **Recurring exam evidence:** repeated in past assessments.
- **Course-taught:** present in lecture/tutorial materials.
- **Inferred priority:** supported by patterns but not explicitly confirmed.
- **Uncertain:** evidence is incomplete or conflicting.
- **External supplement:** not established as part of the course.

## Maintenance rules

- Add new materials to the inventory before using them to broaden the scope.
- Update mastery from the learner's attempts, not from statements such as “I understand.”
- Keep gaps visible rather than filling them silently from generic knowledge.
- Prefer stable source/page references over vague claims.
- Do not modify the original materials. Create or update a persistent course-map artifact only when the user requests it or the project already defines one.
